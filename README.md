# Lutek-and-Stark-2026-strainRate
Raw data (force traces and images), final datasets, and R code for Lutek and Stark 2026.

Below, we detail the data and R code for Lutek and Stark 2026 which are provided in this repository.

Within the repository are two folders: 0_originalData contains the original data files (force traces [csv files] and images) used to generate the datasets for this paper, 1_statsData contains the final datasets and R code used for the statistical analysis and creation of figures.

## 0_originalData_____________________________________________________________________________________

### forceTraces [folder]
This folder contains force traces for each of the animal sets (details found in the main text). Each animal set folder contains data organized by the date on which it was collected. Within each dated folder are the set of force traces collected that day. Each file is named using the following convention: <br/>
“SpurpXXXX-XXX_trXX_XXper[_xxx]” <br/>
where each piece of information in the name is separated by an underscore: the name of the individual (SpurpXXXX-XXX), the trial number (trXX), the loading rate of the trial (XXper) and (for the CA44 and WA2 sets) an indicator of whether it is a tube foot stem trial (tfs) or a tube foot disc (tfd) trial (_xxx). Loading rate indicators correspond to rates in cm s-1 as follows: 15per, 0.45 cm s-1; 30per, 1.1 cm s-1; 45per, 1.7 cm s-1; 60per, 2.35 cm s-1; 75per, 3.1 cm s-1; 90per, 3.6 cm s-1; and 100per, 4.15 cm s-1.

### images [folder]
This folder is organized in the same way as the force traces. Within each dated folder are the images used to determine the morphology of the individual (tube foot disc area, tube foot length), the number of footprints, and the number of broken tube feet. Each file has the name of an individual, an indicator of what the image depicts (tfLength, tube foot length; tfStain, stained footprints and broken tube feet after a whole animal trial; tfArea, tube foot area).

## 1_statsData________________________________________________________________________________________

### figures [folder]
This folder contains pdfs of the figures with graphs created in R (Fig. 2, 3 and S1). These are generated when running the R script _“strainRate_tidyCode”_.

### tables [folder]
This folder contains csv files with the tables created in the script _“strainRate_tidyCode”_.

### 2 statsData [R Project file]
This R project file can be loaded into RStudio to ensure the working folder is set correctly when running the R script _“strainRate_tidyCode”_. Keep this in the same folder as the R Script and data files that follow.

### strainRate_tidyCode [R script]
This R script contains the code used for data analysis. Comments are provided throughout to guide the user through the analysis process.

### tfDPull [data file]
This data file contains data from the tube foot disc pull experiments. Columns are as follows: <br/>
<ins>Individual</ins>: a unique identifier for each sea urchin used in these experiments.<br/>
<ins>Animal Set</ins>: indicators for the animal sets. Details of the sets are provided in the main text.<br/>
<ins>Strain Rate (1/s)</ins>: the strain rate at which each value of tube foot disc tenacity was measured. Details of this calculation can be found in the main text.<br/>
<ins>Tube Foot Disc Tenacity (MPa)</ins>: tube foot disc tenacity (MPa) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the maximum force generated by an individual animal in three trials.

### tfSPull [data file]
This data file contains data from the tube foot stem pull experiments. Columns are as follows:<br/>
<ins>Individual</ins>: a unique identifier for each sea urchin used in these experiments.<br/>
<ins>Animal Set</ins>: indicators for the animal sets. Details of the sets are provided in the main text.<br/>
<ins>Strain Rate (1/s)</ins>: the strain rate at which each set of tube foot stem values was measured. Details of this calculations can be found in the main text.<br/>
<ins>Tube Foot Stem Breaking Force (N)</ins>: the breaking force (N) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the trial where maximum force was generated by an individual animal in three trials.<br/>
<ins>Tube Foot Stem Extension (m)</ins>: the extension (m) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the trial where maximum force was generated by an individual animal in three trials.<br/>
<ins>Tube Foot Stem Initial Spring Constant (N/m)</ins>: the initial spring constant (N/m) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the trial where maximum force was generated by an individual animal in three trials.<br/>
<ins>Tube Foot Stem Final Spring Constant (N/m)</ins>: the final spring constant (N/m) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the trial where maximum force was generated by an individual animal in three trials.<br/>
<ins>Tube Foot Stem Work to Failure (J)</ins>: the work to failure (J) measured for the given urchin. Details of this calculation can be found in the main text. Note that the values included here are based only on the trial where maximum force was generated by an individual animal in three trials.<br/>

### waPull [data file]
This data file contains data from the tube foot stem pull experiments. Columns are as follows:<br/>
<ins>Individual</ins>: a unique identifier for each sea urchin used in these experiments.<br/>
<ins>Animal Set</ins>: indicators for the animal sets. Details of the sets are provided in the main text.<br/>
<ins>Strain Rate (1/s)</ins>: the strain rate at which each set of tube foot stem values was measured. Details of this calculations can be found in the main text. Some missing values are present where videos did not permit clear quantification of the strain rate during the trial. These trials were used for correlations with footprints and broken tube feet, but not elsewhere.<br/>
<ins>Maximum Adhesive Force (N)</ins>: the maximum force (N) measured for the given urchin. Details of this calculation can be found in the main text.<br/>
<ins>Whole Animal Adhesion (N/m2)</ins>: the adhesion (N/m2) measured for the given urchin. Details of this calculation can be found in the main text.<br/>
<ins>Footprints (1/cm2)</ins>: the number of footprints counted (cm-2) for the given urchin. Details of this calculation can be found in the main text.<br/>
<ins>Broken Tube Feet (1/cm2)</ins>: the number of broken tube feet counted (cm-2) for the given urchin. Details of this calculation can be found in the main text.<br/>
